# Results Index

This repository is product-oriented. Current runtime code lives under `src/` and
`speechdamagebench/`; experiment scripts are under `scripts/`.

Historical learning artifacts and day-by-day measurements are preserved on the
`research/learning` branch. New product experiments should add a functional
filename and one row to this index in the same change.

## Reusable experiment entry points

- `scripts/run_day08_experiment.py` — clean versus corrupted ASR baseline
- `scripts/run_day10_experiment.py` — WER/CER and protected-content slices on the frozen benchmark
- `scripts/run_day11_experiment.py` — confidence versus correctness analysis
- `scripts/verify_hinglish_baseline_metrics.py` — reproduce the committed Hinglish baseline aggregate from private artifacts
- `scripts/inspect_hinglish_generation_failures.py` — decoder runtime ceiling and repetition inspection for the frozen cohort
- `scripts/report_hinglish_failure_intelligence.py` — per-clip failure diagnosis with evidence and confidence labels
- `scripts/reserve_hinglish_holdout_pool.py` — freeze the metadata-only final held-out reserve pool
- `scripts/select_hinglish_training_candidates.py` — deterministic random versus intelligent candidate selection
- `scripts/plan_hinglish_decoder_probe.py` — freeze the Phase 7.1 decoder-probe plan (offline dry run by default, `--freeze` writes the committed plan; governed by the pre-registered R1-R4 selection rules)
- `scripts/audit_hinglish_probe_selection.py` — offline audit of the frozen probe plan against the pre-registered selection rules (plan mode 14/14 PASS, plus selection-leakage labeling)
- `scripts/analyze_hinglish_decoder_probe.py` — build the committed decoder-probe metrics aggregate from private run artifacts (clip IDs, counts, and flags only)

## Naming rules

- Reusable source and test modules use functional names.
- Result files should be named for their evaluation scope, not for a day number.
- Audio, checkpoints, and run logs remain gitignored; only manifests, tables, figures, and notes are tracked.

## Measured results

- `results/hinglish/validation_baseline_metrics.json` — frozen 30-utterance speaker-disjoint MUCS-Hinglish validation cohort; corpus WER 296.8% and CER 283.9% driven by 777 insertions from 13 repetitive-hallucination clips (WER without flagged clips 69.7%). Reference transcripts and raw hypotheses stay in the private run archive outside Git. Run date 2026-10-17 (T4, whisper-small @ 973afd24, `hi`/`transcribe`, float16). Metric label: the `composition_bins` rates in this artifact are unlabeled **macro** (mean-of-utterance) values; the corpus-weighted bucket rates are published in the failure intelligence artifact below.
- `results/hinglish/failure_intelligence.json` + `results/hinglish/failure_intelligence.md` — reusable per-clip failure diagnosis of the same frozen cohort, built from private run artifacts (clip IDs, counts, and evidence only; no transcripts). 15/30 clips reached the decoder runtime ceiling with repetition evidence (12 word-level, 3 character-level loops the word heuristic missed), 772/777 insertions are generation-side, and corpus WER excluding generation-side clips is 60.6% versus 296.8% overall. Classifications carry confidence labels; heuristics are evidence, not confirmed hallucination verdicts. Generated by `scripts/report_hinglish_failure_intelligence.py` (2026-10-18, offline).
- `results/hinglish/decoder_probe_plan.json` + `scripts/plan_hinglish_decoder_probe.py` — frozen Phase 7.1 controlled decoder-probe plan (J1): the pre-registered 16-clip development-cohort selection (8 runtime-ceiling word-loop, 3 ceiling char-loop, 2 early-loop, 3 pre-registered control clips), per-clip archived baseline runtimes and SHA-256-verified audio checksums, the C0/C1/C2 generate-kwarg deltas (`max_new_tokens=160`, `no_repeat_ngram_size=4`) against the pinned whisper-small @ 973afd24965f72e36ca33b3055d56a652f456b4d (T4, `hi`/`transcribe`, float16), clip IDs with counts and flags only — no transcripts, no private paths. Conservative estimator: C0 = measured runtimes (45.477 s), C1 = min(measured, 2.0 s) (26.653 s), C2 = max(measured, 3.75 s) (60.0 s), plus model load 90 s and container overhead 60 s → wall 282.13 s, estimated GPU cost $0.046269, timeout worst case $0.06888 (under the 420 s and $0.10 gates). Built offline by `scripts/plan_hinglish_decoder_probe.py` (frozen 2026-10-18, `created_utc` 2026-10-18T14:00:00Z; refuses overwrite without `--force`).
